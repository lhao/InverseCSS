# Inverse CSS — register of known data conditions

Every condition found in the data that code must handle. One entry per condition: what it is, how to detect it, how to handle it, where it applies, and the evidence.

**Rule:** a fix found in one script is implemented once, in the shared module `code/conditions.py` (to be built), and every script uses it. When a handling rule changes, the affected outputs are re-run and the validation metrics compared.

Version 1, 2026-10-15. Status: **implemented** (in a script, not yet shared) / **planned** / **open** (needs investigation).
